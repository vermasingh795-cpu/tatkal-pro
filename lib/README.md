# Tatkal Pro V2.0 — Journey Search Preparation Update

Replace the existing `lib/main.dart` in your GitHub repository with this file.

New in this update:
- Editable From and To station fields
- Travel class selector
- Quota selector
- Copy journey details button
- Open official IRCTC train search button

Important:
- Copying prepares text only; it does not auto-fill IRCTC fields.
- Verify train origin date, station codes, class, quota, and availability on IRCTC.
- No CAPTCHA bypass, automated booking, or payment automation.
